# 67TAX · App real (login + servicios con fotos + calendario)
1. Copia .env.local.example a .env.local y rellena la URL y la clave anon de Supabase.
2. npm install
3. npm run dev  ->  http://localhost:3000
4. En Supabase > Authentication > URL Configuration añade http://localhost:3000 (y tu dirección final) en Redirect URLs.
Zona horaria: NEXT_PUBLIC_TZ está en Atlantic/Canary (Canarias).
